# Week 01 - LTspice Circuit Simulation

## Objective
Learn basic circuit simulation, DC operating point analysis, and voltage divider design using LTspice.

## Experiments

| Experiment | R1 | R2 | Simulated VOUT |
|---|---|---|---|
| W01-D01: Voltage Divider | 1 kOhm | 1 kOhm | 2.500 V |
| W01-D02: Divider Ratio | 1 kOhm | 2 kOhm | 3.333 V |

## Tools
- LTspice 26
- DC Operating Point Analysis (.op)

## Verification
Both simulations matched the calculated voltage divider results.

Note: These results were obtained from circuit simulation, not physical hardware measurements.
